# Telegram Mini App Prototype

Интерактивный прототип Telegram mini app для сервиса транскрибации аудио NewVision.

## Структура экранов
- **Главная** — приветствие, CTA и статистика последних задач.
- **Загрузка** — зона для выбора mp3, подсказки и чек-лист.
- **Статус** — визуализация прогресса воркфлоу n8n и этапы обработки.
- **Результат** — карточка готовой транскрибации с действиями.
- **История** — краткий список последних транскриптов и переход в личный кабинет.

## Использование
Откройте `index.html` в браузере или запустите локальный сервер:

```bash
cd applications/telegram-mini-app
python3 -m http.server 8080
```

Затем перейдите по адресу [http://localhost:8080](http://localhost:8080).

## Интерактивность
- Кнопки и нижняя навигация переключают экраны mini app.
- Загрузка файла отображает превью и включает кнопку отправки.
- «Отправить в n8n» запускает симуляцию прогресса, которая автоматически приводит к экрану результата и обновляет историю.
- Кнопка отмены останавливает сценарий и возвращает к экрану загрузки.
- Доступен быстрый доступ к ссылке на Google Doc и копирование демо-транскрипта.
